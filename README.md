# prettier-config

My personal Prettier configuration, more details are [prettier.io#sharing-configurations](https://prettier.io/docs/en/configuration.html#sharing-configurations).

## How to use?

### 1. Install package.

```sh
pnpm add @linhe0x0/prettier-config -D

# OR npm install @linhe0x0/prettier-config -D
```

### 2. Config to use it.

Add the following configuration to your `package.json`:

```json
{
  "name": "YOUR_NAME",
  "version": "YOUR_VERSION",
  "prettier": "@linhe0x0/prettier-config"
}
```

OR config it in `.prettierrc`:

```
"@linhe0x0/prettier-config"
```
